# cvdp_v1.1.0_agentic_heavy_code_generation_public

This directory contains sanitized Git context bundles for CVDP v1.1.0
agentic-heavy code generation.

Rows supported: 100
Repositories: 40

Each bundle advertises only `refs/heads/context-*` refs used by the supported
dataset rows. Context commits are rewritten parentless synthetic commits with
release-unsafe benchmark scaffolding removed from their trees.

See `manifest.txt` for original-to-sanitized commit mappings.
