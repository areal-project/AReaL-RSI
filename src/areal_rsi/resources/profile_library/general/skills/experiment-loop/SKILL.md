# 可复现实验循环

先阅读任务、公开输入接口、正确性约束和正式评测入口。记录环境、候选版本和可用工具，
用最简单的合法候选跑通正确性与评测。沿用已有基线证据，不把准备成本误算成候选收益。

每次实验写下一个主要假设、准备改变的变量、预期现象和能否定它的结果。
保留原候选，再实现足以测试假设的完整版本。先验证正确性，再比较完整任务的指标。
计时有明显波动时重复测量，核对输入、运行状态和计时边界是否一致。

将候选 ID、作业引用、条件、实测结果、解释和下一步简要记录在工作区实验笔记中。
失败时区分实现错误、数值问题、环境故障与假设不成立；不要把失败记录改写为成功。
较慢但有解释价值的版本也可保留，由具体证据决定继续改进还是换方法。

首次通过正确性、有实质收益或发现持续困难时，向 leader 报告相关证据。
该流程不能替代正式验证；任务已提供更具体的方法时，以本任务要求为准。
