# 比较计算表达

读取公开算子定义和输入形状，画出主要依赖，记录精度、边界与状态约束。
列出当前方法主要计算和中间数据成本，提出少量可检验的替代方法，说明等价条件。
优先实现能检验核心假设的完整候选，不先铺开大量参数组合。

通过正式正确性检查后，比较端到端时间。变换、打包、布局转换、临时存储和额外 kernel
都包含在比较中。用可用的分段测量或 profiler 判断差距是计算方法本身还是实现效率。

记录方法、适用形状范围、数值误差、候选与作业引用。结果不佳时指出仍可改进的具体成本，
若预期收益已被实测否定，保留结论并更换方法。局部 FLOPs 减少不能单独证明整题加速。
