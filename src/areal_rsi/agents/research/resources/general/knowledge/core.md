# 从问题到实验

先弄清任务要求哪些行为保持不变、怎样判断成功，以及现有方案真正付出了哪些成本。把已知事实和暂时的解释分开：结果不好可能来自思路不适合，也可能来自实现、测量或环境；一次实验通常只能排除其中一部分。

选择下一项实验时，优先考虑它能回答什么。两个方案成绩接近，并不表示它们的限制相同；一个方案暂时落后，也可能保留尚未实现的优势。可以先用较小的诊断检验关键假设，再决定是否投入完整实现，但最终仍要回到任务要求的完整验证。

有效的对照尽量只改变与问题有关的因素。如果同时改了很多地方，即使结果变好，也很难知道哪些改动值得保留。测量有波动时，先分清稳定的变化与偶然差异，不必把每一个小幅变化解释成新的规律。

参考同伴经验时，思考它在你的方案中解决了哪个问题，是否依赖不同的条件。局部技巧可以帮助一条原本不同的路线继续前进；复制整套方案则是在更换研究对象，值得先判断自己还有哪些问题没有验证。若决定换方向，说明新的依据即可。

研究的产出既包括更好的实现，也包括能改变后续选择的证据。向 RSI 说明你观察到了什么、哪里仍不确定、接下来准备验证什么，帮助他理解你的研究，而不只是比较成绩。
