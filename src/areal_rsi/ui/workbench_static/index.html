            调整全局目标

            提交后暂停研究员并取消旧作业，保留各自代码，向所有研究员发送新目标。旧成绩保留为历史，新目标需重新验证。已暂停的研究员保持暂停。

            此处调整目标与任务要求，正式验收器、模型、数据集及预算保持原配置。新增要求仍需单独确认验证覆盖。

            未勾选时，新成绩可供参考，但不会自动认定新目标已完成。
