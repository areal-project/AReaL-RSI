## 长流程与恢复测试

自动化场景覆盖三个研究员、24 轮、72 个研究节点。每轮重建 Coordinator 和 worker，检查原会话延续、任务和报告只归档一次、等待期间没有模型调用。节点可以没有候选或验证结果；全量历史仍能分页读取。

还覆盖：旧七字段报告兼容、跨方向订阅作业及公开反馈、私有验证日志不外泄、隐藏工具的未完成调用恢复、报告同时收到补充指令、空最终回复恢复，以及未达标时不能通过 `finish` 提前结束研究。

## 真实模型研究测试

测试采用配置中的 `gpt-6-astra / xhigh` API、真实 DSH 文件/终端工具和本机 CPU。模型自主优化在线缓存策略；分数来自候选代码在六类负载上的实际命中率。目标为 0.80，起点 LRU 为 0.6419167。它是小型研究任务测试，不是 KernelBench 或 Kaggle 性能测试。

每次 run 独立保存会话、工作区、任务、报告、候选和验证记录。没有预写模型回答或候选分数。

| 测试 | 时间预算 | 实际研究员数 | 已完成报告 | 已验证最佳命中率 |
| --- | ---: | ---: | ---: | ---: |
| 第一轮，多方向 | 20 分钟 | 2 | 2 | 0.6419167，仅起点完成验证 |
| 第二轮，单方向 | 20 分钟 | 1 | 1 | 0.7971667 |
| 第三轮，多方向复验 | 30 分钟 | 3 | 3 | 0.7878611 |

**第一轮**：研究员分别尝试频率准入和历史预测，能够自行实现与测试，报告为 641、1,002 字符。但 RSI 接手所有正式验证，候选在时间预算内没有完成验证。这轮还发现测试起点意外包含 `__pycache__`，删除它触发修改范围检查；后续修复测试种子准备，并让错误信息指出具体文件。不能把这轮算作研究成功。

**第二轮**：一个研究员实现小型近期窗口与频率准入策略，735 字符的报告包含具体方法、测试结果和局限。正式验证从 0.6419167 提升至 0.7971667，增加约 15.53 个百分点；RSI 据此在同一方向安排第二轮改进。到时间预算结束时仍未达到 0.80，不能记为目标完成。测试脚本在已经暂停后再次请求暂停，收尾抛出异常；归档和成绩已保存，脚本现已修复该重复调用。

**第三轮**：已出现三个方向并行、自行验证、跨方向分享结果和原会话继续改进。首个候选正式验证为 0.787861；另一个方向得到 0.652917 后明确建议保留最佳版本。RSI 没有据此宣告研究无效，而是让该研究员从最佳候选出发探索另一种增量。首个研究员在报告后等待约 341 秒，没有模型请求，随后在同一会话收到下一轮任务。SLRU 增量的正式分数持平后，研究员还区分了“自测机制有效但未被选用”和“正式运行缺少选择轨迹”，没有把未提升扩张为整个方向无效。最终产生 6 个任务节点、3 份完整报告、4 次 search 验证和 1 次 final 验证；最佳仍为 0.7878611，未达到 0.80，按预算暂停。final 使用本测试同一验证协议，不代表独立留出集。报告为 688–905 字符，任务指令为 118–220 字符。

第一轮有 15 次 API 重试，第二轮 16 次，第三轮 46 次；均保留原请求重试，没有切换模型。第三轮记录 97 次逻辑模型调用、1,270,692 个 API 报告 token、零次 compact。应将服务端等待与模型决策效率分别分析。三次测试使用的是同一精简方向的迭代实现，不构成严格的单/多 Agent 对照实验。

第三轮进程没有重启加载测试期间的工具修正：四次文件读取请求超过旧的 200 行上限，一次起点 ID 缺失，收尾也遇到上述重复暂停异常。最终实现已提高并公开读取上限、提供起点身份，并通过单独的预算到期测试确认脚本退出码为 0、模型调用为 0。该 run 的原记录保持原样，不把后补修复记成它已经使用的行为。

行为上仍有不足：最初三个方向的范围有重叠，RSI 起初集中承接验证，剩余时间很少时仍安排了新的尝试。后续可以优先用一个研究员跑完整闭环；需要并行时再检验各方向是否实际互补。本次没有用额外的强制派单规则掩盖这些模型决策问题。

## 检查与复现

最终回归：**474 项测试、64 个子测试通过**，耗时 114.81 秒，包含真实 DSH 集成。Ruff、Mypy（131 个源文件）和工作台/DSH worker 的 JavaScript 语法检查通过。

```bash
RSI_DSH_TOOLS_TEST_INSTALLATION=/absolute/path/to/dsh-tools/<digest> \
  uv run --locked pytest -q -o addopts=''
uv run --locked ruff check src tests scripts/evaluate_research_team.py examples/research_lab
uv run --locked mypy src tests

uv run --locked python scripts/evaluate_research_team.py --agents 1 --minutes 20
uv run --locked python scripts/evaluate_research_team.py --agents 3 --minutes 30
```
